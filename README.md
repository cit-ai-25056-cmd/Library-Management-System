# Library-Management-System
مشروعنا نظام إدارة مكتبة. Book يمثل الكتاب، وEBook يرث منه. البرنامج يضيف الكتب، يعرضها، يستعيرها ويرجعها. استخدمنا Encapsulation لحماية البيانات، وInheritance بالـEBook، وPolymorphism بتغيير دالة العرض، وFunction Overloading بدالة الاستعارة، مع Constructors وDestructors
